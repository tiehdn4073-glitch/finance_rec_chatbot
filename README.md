# 💰 FinanFit

> **개인 금융정보를 기반으로 금융상품을 추천하고, AI 상담을 제공하는 맞춤형 금융상품 추천 서비스**

FinanFit은 사용자의 **나이, 성별, 투자성향, 직업, 소득** 등의 정보를 바탕으로 금융상품을 추천하고, OpenAI API를 활용한 AI 금융상품 상담 기능을 제공하는 웹 서비스입니다.

## 📝 프로젝트 소개

금융상품은 상품 종류와 가입 조건이 다양하지만, 사용자가 자신의 상황에 적합한 상품을 직접 비교하기에는 어려움이 있습니다.

**FinanFit**은 사용자의 금융정보를 입력받아 개인의 특성에 맞는 금융상품을 추천하고, 추가적인 궁금증은 AI 상담을 통해 해결할 수 있도록 구현한 서비스입니다.

### 핵심 목표

* 개인 금융정보 기반 맞춤형 금융상품 추천
* 금융상품 데이터를 활용한 상품 비교
* AI 기반 금융상품 상담
* 회원가입 및 로그인 기반 개인화 서비스 제공

---

## ✨ 주요 기능

### 1. 회원가입

사용자의 금융정보를 입력받아 개인화된 추천에 활용합니다.

* 아이디 / 비밀번호
* 이름
* 이메일
* 나이
* 성별
* 투자성향
* 직업
* 연소득
* 프로필 이미지

입력된 사용자 정보는 SQLite 데이터베이스에 저장됩니다.

---

### 2. 로그인 / 로그아웃

SQLite 기반 사용자 인증 기능을 구현했습니다.

* 로그인
* 로그아웃
* 세션 기반 사용자 인증
* 비밀번호 해싱
* 로그인 상태에 따른 페이지 접근 제어

비밀번호는 `PBKDF2-HMAC-SHA256` 방식으로 해싱하여 저장합니다.

---

### 3. 맞춤형 금융상품 추천

사용자의 금융정보와 `예금목록.csv`에 저장된 금융상품 데이터를 비교하여 추천 점수를 계산합니다.

추천에 활용되는 사용자 정보:

* 투자성향
* 나이
* 직업
* 소득

상품 정보에서 다음과 같은 키워드를 분석합니다.

* 예금
* 적금
* 청년
* 직장인
* 사회초년생
* 시니어
* 노후
* 우대금리
* 금리 등

추천 점수가 높은 상품을 기준으로 **상위 3개 상품**을 메인 화면에 제공합니다.

---

### 4. AI 금융상품 상담

OpenAI API를 활용하여 사용자의 금융상품 관련 질문에 답변합니다.

AI에게 다음 정보를 함께 전달합니다.

* 사용자 나이
* 투자성향
* 직업
* 연소득
* 금융상품 데이터

또한 AI가 존재하지 않는 금리나 가입조건을 임의로 생성하지 않도록 상담 규칙을 설정했습니다.

예시 질문:

* `저에게 추천상품을 알려줘`
* `예금과 적금의 차이가 뭐야?`
* `저에게 어떤 상품이 잘 맞아?`

---

### 5. 반응형 웹 UI

HTML/CSS를 이용하여 로그인, 회원가입, 금융상품 추천, AI 상담 화면을 구현했습니다.

모바일 화면에서도 사용할 수 있도록 반응형 레이아웃을 적용했습니다.

## 🛠 사용 기술

### Backend

| 기술      | 용도              |
| ------- | --------------- |
| Python  | 백엔드 개발          |
| FastAPI | 웹 서버 및 API 구현   |

| 기술         | 용도                 |
| ---------- | ------------------ |
| HTML5      | 웹 페이지 구조           |
| CSS3       | UI 및 반응형 디자인       |
| JavaScript | AI 챗봇 비동기 통신       |
| Fetch API  | `/api/chat` API 호출 |

### AI / Data

| 기술         | 용도          |
| ---------- | ----------- |
| OpenAI API | AI 금융상품 상담  |

* PBKDF2-HMAC-SHA256 기반 비밀번호 해싱

* `HttpOnly` Cookie 적용
* `SameSite=Lax` 적용

## 🧠 추천 알고리즘

FinanFit은 별도의 머신러닝 모델을 학습시키는 방식이 아니라, **사용자 정보와 금융상품의 속성을 비교하여 점수를 계산하는 규칙 기반 추천 방식**을 사용합니다.

### 추천 과정

```text
사용자 정보 입력
      ↓
사용자 특성 분석
      ↓
금융상품 CSV 데이터 로드
      ↓
상품별 추천 점수 계산
      ↓
점수 기준 정렬
      ↓
상위 3개 상품 추천
```

### 점수 계산 예시

#### 투자성향

**안정형**

* 예금 → +12
* 적금 → +8
* 원금 관련 키워드 → +3

**중립형**

* 예금 → +8
* 적금 → +8

**공격형**

* 금리 → +8
* 우대 → +5

#### 연령

예를 들어 19~29세 사용자의 경우:

* 청년 → +10
* 주니어 → +10
* 사회초년생 → +10
* 2030 → +10

등의 방식으로 점수를 부여합니다.

#### 직업

사용자의 직업과 상품 정보가 일치하는 경우 추가 점수를 부여합니다.

#### 금리

상품의 금리 정보를 추출하여 금리가 높은 상품에 추가 점수를 부여합니다.

최종적으로 계산된 점수를 기준으로 상품을 정렬하여 상위 3개 상품을 추천합니다.

## 🤖 AI 상담 동작 방식

사용자가 챗봇에서 질문을 입력하면 JavaScript의 `fetch()`를 통해 FastAPI 서버의 `/api/chat` 엔드포인트로 요청을 전달합니다.

```text
사용자 질문
    ↓
JavaScript fetch()
    ↓
POST /api/chat
    ↓
현재 로그인 사용자 확인
    ↓
사용자 금융정보 + 상품 데이터 구성
    ↓
OpenAI API 요청
    ↓
AI 답변 생성
    ↓
JSON 응답
    ↓
챗봇 화면에 출력
```

AI 상담에서는 CSV에 존재하지 않는 금리나 가입조건을 임의로 생성하지 않도록 프롬프트에서 제한하고 있습니다.

## 🚀 실행 방법

### 1. 프로젝트 다운로드

GitHub에서 프로젝트를 clone합니다.

```bash
git clone https://github.com/USERNAME/FinanFit.git
cd FinanFit
```

---

### 2. 가상환경 생성

Windows 기준:

```bash
python -m venv venv
```

가상환경 활성화:

```bash
venv\Scripts\activate
```

---

### 3. 필요한 라이브러리 설치

```bash
pip install fastapi uvicorn jinja2 python-multipart python-dotenv openai
```

---

### 4. 환경변수 설정

프로젝트 루트에 `.env` 파일을 생성합니다.

```env
OPENAI_API_KEY=your_openai_api_key
```

AI 상담 기능을 사용하려면 OpenAI API Key가 필요합니다.

---

### 5. 서버 실행

```bash
python main.py
```

서버가 실행되면 브라우저에서 다음 주소로 접속합니다.

```text
http://127.0.0.1:1439
```

또는 다음 명령어로 실행할 수도 있습니다.

```bash
uvicorn main:app --host 127.0.0.1 --port 1439 --reload
```

## 🖥 화면 구성

### Login

사용자가 아이디와 비밀번호를 입력하여 로그인합니다.


금융상품에 대한 질문을 입력하면 사용자 정보를 고려하여 AI가 답변합니다.
